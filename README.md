# 🔧 Predictive Maintenance Project

Machine Learning project focused on predictive maintenance using industrial operational data.

---

# 📌 Overview

This project aims to predict equipment failures based on operational variables such as:

- Temperature
- Vibration
- Pressure
- Operating Hours

The objective is to identify patterns associated with failures and support predictive maintenance strategies in industrial environments.

---

- Scikit-learn
- Jupyter Notebook

# 🧠 Machine Learning

The model was trained using:

- Decision Tree Classifier

Performance metrics included:

- Accuracy
- Confusion Matrix
- Feature Importance

---

# 📈 Visual Analysis

The project includes:

- Scatter plots
- Correlation heatmaps
- Failure distribution charts
- Operational KPI dashboard

---

# 🔥 Key Insights

The analysis demonstrated strong correlation between:

- High vibration
- High temperature
- Pressure variation

and the occurrence of operational failures.
